# Mathématiques et signal - Climate project (Strasbourg-Entzheim, 1950-2024)

Analysis of daily weather data: periodicities (Fourier), sampling and aliasing,
filtering and autocorrelation. Group project, due on Moodle on 10/11/2026.

## Installation

Python 3.9 or newer is required. From the project folder:

    pip install -r requirements.txt

Libraries used: numpy, pandas, matplotlib, scipy.

## How to run

Always run the scripts from the project root folder (the one containing `data.py`),
because the paths `data/...` and `figures/...` are relative.

    python data.py        # quick test of the loader
    python q1_stats.py    # prints the statistics and saves the Q1 figures

## Using the shared data module

    from data import load_series

    tavg = load_series("tavg")   # mean temperature (°C), pandas Series
    prcp = load_series("prcp")   # precipitation (mm), pandas Series
    x = tavg.values              # numpy array, for FFT / filters
    fs = 1.0                     # sampling frequency: 1 sample per day

`load_series(var)` returns a Series with a daily DatetimeIndex
(1950-01-01 to 2024-12-31, 27394 values) and no missing value.

## About the data

- 27394 daily values, no missing day.
- Variables used: `tavg` (mean temperature) and `prcp` (precipitation).
  Both are 100 % complete, so nothing is filled.
- Other variables have many gaps and are not recommended: snow 15 % missing,
  wspd 33 %, wpgt 41 %, tsun 47 %, pres 60 %. `wdir` is entirely empty.
  For these, `load_series` only interpolates gaps of 5 days or fewer
  and prints a warning if NaN remain.
- Sampling frequency: 1 sample/day, so the Nyquist frequency is 0.5 cycle/day.

only 19 values and is excluded.
